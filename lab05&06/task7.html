Method 2: Flexbox Layout

Modern
Header (flex container)
Navigation (flex: 0 0 200px)
Main Content (flex: 1)
Flexbox makes equal height columns easy! All columns automatically have the same height regardless of content.
Sidebar (flex: 0 0 200px)
Footer

CSS Code:

.flex-layout {
    display: flex;
    flex-direction: column;
}
.flex-layout .content-row {
    display: flex;
    flex: 1;
}
.flex-layout .nav {
    flex: 0 0 200px;
}
.flex-layout .main {
    flex: 1;
}
.flex-layout .sidebar {
    flex: 0 0 200px;
}

Method 3: CSS Grid Layout

Most Powerful
Header (grid-area: header)
Navigation (grid-area: nav)
Main Content (grid-area: main)
Grid provides the most concise and intuitive way to create this layout. Just define the grid template areas and you're done!
Sidebar (grid-area: sidebar)
Footer (grid-area: footer)

CSS Code:

.grid-layout {
    display: grid;
    grid-template-rows: auto 1fr auto;
    grid-template-columns: 200px 1fr 200px;
    grid-template-areas: 
        "header header header"
        "nav main sidebar"
        "footer footer footer";
}
.header { grid-area: header; }
.nav { grid-area: nav; }
.main { grid-area: main; }
.sidebar { grid-area: sidebar; }
.footer { grid-area: footer; }

📱 Responsive Behavior

Resize the browser window to see how all three layouts stack on mobile:

  • Float: All elements become 100% width (floats cleared)
  • Flexbox: Content row becomes column using flex-direction
  • Grid: Grid areas are redefined for mobile layout

💡 Recommendation

Use Float When:

  • Supporting ancient browsers
  • Building email templates
  • Simple text wrapping around images

Use Flexbox When:

  • Building component-level layouts
  • Need one-dimensional alignment
  • Creating navigation bars
  • Card layouts with equal heights

Use Grid When:

  • Building page-level layouts
  • Need two-dimensional control
  • Complex overlapping designs
  • Asymmetric layouts

Best Practice: Combine all three! Use Grid for page structure, Flexbox for components, and Float only when needed for text wrapping.
